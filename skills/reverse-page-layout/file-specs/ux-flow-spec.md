# UX Flow & Interaction Pattern Specification

## Purpose

This document defines the JSON schemas for two output artifacts produced during Phase 3 (UX Flow Mapping) of the `reverse-page-layout` skill:

1. **`user-journey.json`** — Describes the step-by-step user journey through the page, from entry to conversion or exit.
2. **`interaction-patterns.json`** — Catalogs the interaction and animation patterns observed on the page, including scroll-triggered effects, hover states, click interactions, and responsive behaviors.

These artifacts are generated by a sub-agent that reads this spec, analyzes the extraction output from Phase 0, and optionally inspects the live page for interaction cues.

---

## user-journey.json Schema

```json
{
  "brand": "string — the brand or site name extracted from the page",
  "entryPoint": "string — the full URL of the page analyzed",
  "primaryGoal": "string — what the user is trying to accomplish on this page (inferred from content, CTAs, and layout)",
  "steps": [
    {
      "step": 1,
      "action": "string — the user action at this step (e.g., 'view hero', 'scroll to features', 'click pricing CTA')",
      "section": "string — the section type where this action occurs (e.g., 'hero', 'features', 'pricing', 'cta-banner')",
      "intent": "string — the user's intent or mental state at this step (e.g., 'understand value proposition', 'compare options')",
      "nextAction": "string — the expected next action the user takes (e.g., 'scroll to features', 'click signup')",
      "timeOnSection": "string — estimated seconds the user spends at this step (e.g., '3-5s', '10-15s')"
    }
  ],
  "conversionPath": [
    "string — human-readable path from entry to primary conversion (e.g., 'view hero → scroll to features → view pricing → click signup CTA')"
  ],
  "exitPoints": [
    "string — possible exit points (e.g., 'footer social links', 'navigation to blog', 'bounce after hero')"
  ],
  "navigationPattern": "string — one of: 'sticky-nav', 'hidden-nav', 'burger-menu', 'fixed-nav', 'scroll-aware-nav'"
}
```

### Field Rules

| Field | Type | Required | Description |
|---|---|---|---|
| `brand` | string | yes | Extracted from `<title>`, logo alt text, or meta tags |
| `entryPoint` | string | yes | The URL that was navigated to in Phase 0 |
| `primaryGoal` | string | yes | Inferred from the page's primary CTA, hero heading, and overall content |
| `steps` | array | yes | Minimum 3 steps required (Gate 3) |
| `steps[].step` | number | yes | Sequential integer starting at 1 |
| `steps[].action` | string | yes | Short verb phrase describing the user action |
| `steps[].section` | string | yes | Must match a section type from the standard set |
| `steps[].intent` | string | yes | The user's goal or question at this step |
| `steps[].nextAction` | string | yes | What the user does next; `null` or `"exit"` for the final step |
| `steps[].timeOnSection` | string | yes | Estimated time range (informed by section content density) |
| `conversionPath` | array | yes | Array of step descriptions forming the primary path to conversion |
| `exitPoints` | array | yes | At least 1 exit point required |
| `navigationPattern` | string | yes | Must match one of the enumerated values |

### navigationPattern Values

| Value | Description |
|---|---|
| `sticky-nav` | Navigation stays visible at top as user scrolls (position: sticky) |
| `hidden-nav` | Navigation is not persistently visible; may appear on scroll up |
| `burger-menu` | Navigation collapsed into hamburger menu (mobile or all widths) |
| `fixed-nav` | Navigation is fixed to viewport (position: fixed), always visible |
| `scroll-aware-nav` | Navigation changes appearance/behavior based on scroll position |

## interaction-patterns.json Schema

```json
{
  "brand": "string — the brand or site name",
  "patterns": [
    {
      "name": "string — human-readable pattern name (e.g., 'scroll-triggered-fade-in')",
      "type": "string — interaction category: 'scroll', 'hover', 'click', 'auto-rotate', 'sticky', 'parallax', 'video-bg'",
      "trigger": "string — technical trigger description (e.g., 'IntersectionObserver at 50% viewport', 'mouseenter on .card', 'click on .accordion-header', 'setInterval 5000ms')",
      "effect": "string — visual effect description (e.g., 'fade-in-up', 'translateY(-4px) + shadow-3', 'accordion expand', 'slide next card', 'background-attachment: fixed')",
      "duration": "string — animation duration (e.g., '0.6s', '0.3s', 'instant')",
      "easing": "string — easing function (e.g., 'ease-out', 'ease-in-out', 'cubic-bezier(0.4, 0, 0.2, 1)', 'none')",
      "sections": ["string — section types where this pattern appears (e.g., 'section-feature-grid', 'section-testimonials')"]
    }
  ],
  "responsiveBehaviors": [
    {
      "breakpoint": "string — the breakpoint width (e.g., '768px', '375px')",
      "changes": [
        "string — description of what changes at this breakpoint (e.g., 'grid 3-col → 1-col', 'nav → hamburger', 'hero min-height 600→400')"
      ]
    }
  ]
}
```

### Pattern Types (Interaction Catalog)

The sub-agent should identify patterns from the following catalog. If a pattern type is not detected, it is simply omitted from the output. An empty `patterns` array is valid (see Decision Rules).

| Type | Description | Common Triggers |
|---|---|---|
| `scroll` | Scroll-triggered animations | IntersectionObserver, scroll event listeners; effects: fade-in, slide-up, scale-in, stagger |
| `hover` | Hover effects on interactive elements | mouseenter/mouseover; effects: card lift, color change, image zoom, underline grow |
| `click` | Click/tap interactions | click event; effects: accordion toggle, modal open, tab switch, dropdown expand |
| `auto-rotate` | Automatically rotating content | setInterval/setTimeout; effects: carousel slide, testimonial rotation, logo cloud cycle |
| `sticky` | Sticky or fixed elements | position: sticky/fixed; effects: nav sticks on scroll, sidebar follows content, CTA bar appears |
| `parallax` | Parallax scrolling effects | background-attachment: fixed, transform on scroll; effects: background moves slower than content |
| `video-bg` | Video or autoplay backgrounds | `<video autoplay loop muted>`; effects: looping background video in hero |

## Detection Guidance

The sub-agent generating these files should use the following signals to detect patterns:

### Scroll-Triggered Animations
- Look for CSS classes like `fade-in`, `animate`, `reveal`, `aos`, `scroll-trigger` in the extraction component data.
- Check for inline styles with `opacity: 0` or `transform: translateY(...)` on elements that are below the fold.
- Look for `<script>` tags referencing IntersectionObserver or scroll listeners (note: these are observed, not replicated in templates).

### Hover Effects
- Check computed styles for `:hover` rules — look for transition properties on cards, buttons, links.
- Common indicators: `transition: transform 0.3s`, `:hover { transform: translateY(...) }`.

### Click Interactions
- Look for elements with `aria-expanded`, `role="tab"`, accordion patterns (`details`/`summary`), or class names containing `accordion`, `tab`, `modal`, `dropdown`.

### Auto-Rotating Content
- Detect carousels by class names (`carousel`, `slider`, `swiper`, `slick`).
- Multiple testimonials or cards with only one visible at a time suggest rotation.

### Sticky Elements
- Already captured in the navigation extraction (Script 3). Check for `position: sticky` or `position: fixed` on non-nav elements (sidebars, CTA bars).

### Parallax
- Look for `background-attachment: fixed` in computed styles of banner/CTA sections.
- Check for transform-based parallax via script-detectable class names.

### Video Backgrounds
- Search for `<video>` elements with `autoplay`, `loop`, `muted` attributes in hero or banner sections.

---

## Minimum Requirements (Gate 3)

- `user-journey.json` must have at least 3 steps in the `steps` array.
- `interaction-patterns.json` must have at least 2 entries in the `patterns` array. If fewer than 2 patterns are detected, see `decision-rules.md` for the fallback policy.
- `responsiveBehaviors` should have at least 1 entry covering the 768px breakpoint (since all responsive templates target this breakpoint).
